# Earth Observation-Based Urban Ecosystem Services in Delhi

## Overview

This repository contains the R scripts associated with a research study assessing carbon storage and stormwater retention in Delhi, India, using an integrated geospatial modelling framework.

## Methods

The study combines Earth Observation-derived land-use/land-cover information, InVEST ecosystem-service modelling, Random Forest analysis and Geographically Weighted Regression.
